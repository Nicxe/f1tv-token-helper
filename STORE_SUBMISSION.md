### Detailed description

```text
THIS EXTENSION IS FOR BETA TESTING.

F1TV Token Helper connects your own Formula 1 browser session to F1 Sensor in Home Assistant.

The extension reads the F1TV live timing token from your local browser session and sends it to your own Home Assistant instance through a short-lived pairing flow. It does not ask for your Formula 1 password, does not store your token permanently, and does not send your token to a project server.

How it works:
1. Start Connect F1TV access in the F1 Sensor integration.
2. Open the pairing page from Home Assistant.
3. Open this extension.
4. Sign in to Formula 1 if needed.
5. Select Fetch.
6. Select Send to Home Assistant.

Public F1 Sensor live timing continues to work without F1TV access. F1TV access is optional and is used only for experimental authenticated live timing data in supported F1 Sensor builds.

This extension is an unofficial companion for F1 Sensor. It is not affiliated with, endorsed by, or associated with Formula 1, F1TV, FIA, or Formula One Licensing B.V.
```

## Permission Justifications

Use these justifications in the Chrome Web Store Developer Dashboard.

### `cookies`

```text
Required to read the user's Formula 1 browser session cookie on allowed Formula 1 domains so the extension can find the F1TV live timing token locally. The extension does not read unrelated cookies and does not send cookies to a project server.
```

### `activeTab`

```text
Required so the extension can read the active pairing page or active Formula 1 tab after the user opens the extension. This lets the helper detect the Home Assistant pairing link and find token data only from the tab the user is using.
```

### `scripting`

```text
Required to inspect the active Formula 1 tab for local session data when the user selects Fetch. The extension uses this only after user interaction and does not inject persistent scripts.
```

### `clipboardWrite`

```text
Required for the Advanced manual export fallback, where the user can copy a Home Assistant Bearer value for development or troubleshooting.
```

### `storage`

```text
Required to temporarily keep the Home Assistant pairing session while the user signs in to Formula 1 and returns to the extension. The F1TV token is not stored in chrome.storage.
```

### Host permissions

Formula 1 host permissions:

```text
Required only for Formula 1 domains so the extension can read the user's local Formula 1 session and extract the F1TV live timing token.
```

Optional Home Assistant host permissions:

```text
Requested only when the user selects Send to Home Assistant. This allows the extension to send the token to the specific Home Assistant callback URL generated by the pairing flow.
```

## Review Notes

Paste this into the reviewer notes field if available:

```text
This extension is an unofficial companion for the F1 Sensor Home Assistant integration. It has a single purpose: let a user send their own local F1TV live timing token to their own Home Assistant instance through a short-lived pairing flow.

The extension does not ask for Formula 1 usernames or passwords. It does not send tokens, cookies, telemetry, or analytics to a project server. It stores only temporary Home Assistant pairing data in chrome.storage.session so the user can sign in to Formula 1 and return to the popup without losing the pairing. The F1TV token itself is kept only in popup memory and cleared after success, clear, or popup close.

The optional Home Assistant host permission is requested only when the user sends the token to the pairing callback URL generated by their own Home Assistant instance.
```
